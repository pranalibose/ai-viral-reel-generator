Module 1

Welcome to the Vibe Coding Era 🚀

Software development is shifting. Instead of writing code line-by-line, we are now orchestrating autonomous AI agents to build entire functional apps from scratch.

Classical Coding

  • Spending hours memorizing syntax
  • Finding a missing bracket or semicolon
  • Slow, incremental development cycles
  • Focus on writing code logic

Vibe Coding (Orchestrating)

  • Communicating in descriptive prompts
  • Focusing on UI, system flow, & UX
  • Rapid prototyping in minutes
  • Directing AI agents (e.g. Antigravity)

💡 Learning to code is no longer about syntax; it is about system design and describing what you want clearly.

Module 2

API Orchestration: The Restaurant Analogy 🍽️

Click each node on the map to see how our app uses different APIs to build the video:

The Customer (Frontend App) Looks at menu, orders video generation
The Waiter (FastAPI Server) Sends orders to LLM, Speech, and Assets
The Chef (Google Gemini 1.5 Flash) Brainstorms script segments & keywords
The Plater (FFmpeg Video Editor) Merges clips, styles captions, and mixes audio

The Customer (Frontend App)

This is the glassmorphic webpage where the user enters script themes, selects visual layouts, and clicks "Generate". It acts as the customer placing the order. It has no video compiling capacity; it just displays the gorgeous preview output.

Interactive Prompt Evaluator (COSTAR) ✍️

Write or edit the agent prompt below. Press **Evaluate Prompt** to see if it satisfies the COSTAR framework guidelines!

COSTAR Score: 40%
Context (e.g., "You are...")
Objective (Clear task)
Style/Aesthetics (Visual styles)
Response format (e.g. JSON)
💡 **Tip:** Add context (e.g., "You are a senior python developer") and define a structured output format (like Pydantic/JSON models) to get better results.
